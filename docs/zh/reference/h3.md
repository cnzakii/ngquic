# HTTP/3

`ngquic.h3` 在 QUIC 连接之上实现 HTTP/3（[RFC 9114](https://www.rfc-editor.org/rfc/rfc9114)）和 QPACK（[RFC 9204](https://www.rfc-editor.org/rfc/rfc9204)）。向 `Endpoint.connect()` 或 `Incoming.accept()` 传入 `h3=H3Config()`，得到的就是 `H3Connection`；连接生命周期、定时器和路径都继承自 [`BaseConnection`](connections.md#ngquic.BaseConnection)。
